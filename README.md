# Financial Dashboard Chart-js 💰

Um sistema de controle financeiro pessoal desenvolvido com JavaScript puro. O projeto permite que o usuário gerencie receitas e despesas, calculando o saldo em tempo real e visualizando a distribuição dos gastos por categoria através de gráficos dinâmicos.

## 🚀 Propósito
Este projeto foi desenvolvido para consolidar conhecimentos em manipulação avançada do DOM, persistência de dados com LocalStorage e integração de bibliotecas de terceiros (Chart.js). É uma ferramenta prática para organizar metas financeiras, como economias para projetos pessoais.

## ✨ Funcionalidades
* **Saldo em Tempo Real:** Cálculos automáticos de balanço total, receitas e despesas ao adicionar transações.
* **Visualização de Dados:** Gráfico de rosca interativo que categoriza despesas para uma análise visual rápida.
* **Persistência de Dados:** Uso de `localStorage` para manter as transações salvas mesmo após fechar o navegador.
* **Interface Responsiva:** Design limpo e focado na experiência do usuário (UX).

## 🛠️ Tecnologias Utilizadas
* **HTML5 & CSS3:** Uso de propriedades customizadas e Flexbox para o layout.
* **JavaScript (ES6+):** Aplicação de métodos de array como `filter`, `map` e `reduce` para lógica de negócio.
* **Chart.js:** Biblioteca externa para a geração de gráficos dinâmicos.
